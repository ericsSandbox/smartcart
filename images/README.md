# SmartCart Logo

## Adding the Logo Image

1. Save the SmartCart logo image (the one with the brain-powered shopping cart) as `smartcart-logo.png` in this directory

2. The logo should be:
   - PNG format
   - Transparent background
   - Approximately 500x500 pixels (will be displayed at 120x120)
   - High resolution for crisp display on all devices

3. Once saved, the app will automatically display it in the header

## Current Status

- 2x2 button layout (Pantry/Home on left, Shopping/Meals on right)
- Fallback emoji (🛒) if image isn't available
